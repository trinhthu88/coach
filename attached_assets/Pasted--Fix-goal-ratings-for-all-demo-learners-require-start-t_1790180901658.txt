## 2. App fix — require start and target when creating a goal

The goal creation flow currently allows empty start and target values,
then locks them with "Locked after your next completed session."

Change this:

a) In the goal creation form (find the React component — likely in
   src/pages/ or src/components/ under goals), make Start and Target
   REQUIRED fields. The form should not submit without both values.

b) Remove the "Locked after your next completed session" behaviour
   for Start and Target. These are set by the learner when they
   create the goal, not after a session.

c) "Current" is the only value that updates after sessions — this
   one CAN start empty and gets populated after the first completed
   session where the learner rates their goal.

d) So the flow becomes:
   - Create goal: learner sets Start (required) and Target (required)
   - After each coaching session: learner rates Current
   - The goal wheel shows Start → Current → Target progression

e) Check if there's a database constraint that should enforce
   NOT NULL on the start and target rating rows. If not, consider
   adding one in a migration.

f) The "Locked" UI should only apply to Current (not Start/Target):
   "Your current rating is captured after each session"
