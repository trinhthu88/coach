---
name: Training learning breakdown configuration
description: How legacy Training child-content configuration becomes canonical four-type evidence.
---

Legacy Training modules with a null `learning_components` value may be explicitly opted into Skill Cards, Quizzes, Reflections, and Daily Prompts only when the selected visible Training weeks contain the relevant visible content. Explicit Admin selections must never be overwritten.

**Why:** The canonical projection deliberately excludes optional, hidden, unavailable, or unselected content. Inferring all child types without checking visible selected content would turn optional activity into required progress.

**How to apply:** Keep Learner and Sponsor on their role-scoped wrappers over the same canonical breakdown. Preserve the Training selected-week denominator separately from child learning evidence.
